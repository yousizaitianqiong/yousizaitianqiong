# 高原眼病智能筛查平台

> 脱敏项目档案｜模型端负责人｜2025.07 - 2026.05

## 项目概览

该项目面向高原地区眼病筛查场景，基于 RETFound（ViT-Large）构建参数高效的疾病识别流程。训练阶段融合合作医院私有眼底数据与公开数据，覆盖 15 类疾病；工程阶段通过异步推理与 REST API 完成模型服务联调。

本页面只记录可公开的技术路线、个人贡献和汇总指标，不提供任何患者数据、标签明细、模型权重或线上服务信息。

## 技术方案

```mermaid
flowchart LR
    A[脱敏数据索引] --> B[分层采样与数据增强]
    B --> C[RETFound / ViT-Large]
    C --> D[Adapter / PEFT]
    D --> E[分类与指标评估]
    E --> F[RabbitMQ 异步推理]
    F --> G[REST API 联调]
```

- **任务拆分：**构建二分类分治框架，覆盖 8 类眼底疾病和 7 类眼前段疾病。
- **参数高效训练：**引入 Adapter / PEFT，在保留预训练表征能力的同时降低可训练参数量、训练时间和显存占用。
- **类别不平衡：**围绕极重度长尾分布设计分层采样与强增强策略，并统一评估 Accuracy、AUC-ROC 与 Macro F1。
- **工程链路：**通过 RabbitMQ 接入云端推理服务，并完成前后端 REST API 联调。

## 已验证结果

| 项目 | 结果 |
| --- | --- |

| 最优单类结果 | 95.94% |
| 测试集综合指标 | 89.73% Accuracy / 0.935 AUC-ROC / 0.809 Macro F1 |
