# 处处闻啼鸟 - 鸟鸣声识别与应用平台

> 脱敏项目档案｜国家级大学生创新训练计划核心成员｜2024.12 - 2025.10

## 项目概览

该项目围绕鸟鸣音频识别、众包标注与 Web 应用展开，覆盖音频上传、多源数据预处理、单／多标签识别、动态地图展示和关键词驱动的鸟鸣合成。本人主要参与数据与模型实验，并协助平台功能完善和前后端联调。

本页面只展示可公开的技术方案、个人贡献和汇总结果，不转载团队源码、用户数据库、邮件配置、模型权重或来源不明确的音频素材。

## 技术方案

```mermaid
flowchart LR
    A[多源鸟鸣音频] --> B[切分、降噪与尺度整理]
    B --> C[HuBERT 迁移微调]
    C --> D[注意力掩码与掩码感知 GAP]
    D --> E[单／多标签识别]
    E --> F[Flask / Jinja2 应用]
    F --> G[地图展示与众包标注]
```

- **数据与模型：**参与多源数据清洗、音频切分与降噪，构建跨尺度训练集并开展 HuBERT 迁移实验。
- **算法改进：**提出智能注意力掩码与掩码感知 GAP，用于增强不同数据规模下的鲁棒性。
- **平台联调：**参与 Flask / Jinja2 功能完善，协助登录注册、动态分布地图、众包标注与音频上传流程；使用 Fetch / FormData 与 AMap JS API 完成异步交互和地图数据回显。
- **应用流程：**串联单／多标签识别、关键词驱动鸟鸣合成、云端部署和众包标注。
